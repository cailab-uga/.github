## Cai Lab

Computational systems biology at the University of Georgia — led by [James Cai](https://github.com/jamesjcai).

We develop machine-learning methods for single-cell genomics: gene regulatory
network inference, virtual knockout and perturbation analysis, cell–cell
interaction detection, and quantum / quantum-inspired algorithms for genomics.

### Software

| | |
|---|---|
| [scGEAToolbox](https://github.com/jamesjcai/scGEAToolbox) | MATLAB toolbox for single-cell gene expression analysis |
| [scTenifoldNet](https://github.com/cailab-tamu/scTenifoldNet) | Construct and compare single-cell GRNs across conditions |
| [scTenifoldKnk](https://github.com/cailab-tamu/scTenifoldKnk) | Virtual knockout experiments on single-cell GRNs |
| [scTenifoldXct](https://github.com/cailab-tamu/scTenifoldXct) | Manifold learning for cell–cell interaction detection |
| [QuantumGRN](https://github.com/cailab-tamu/QuantumGRN) | Variational quantum circuits for GRN inference |
| [qSimCells](https://github.com/cailab-tamu/qSimCells) | Quantum generative modeling of single-cell transcriptomes |
| [Spline-DV](https://github.com/cailab-tamu/Spline-DV) | Spline-based differential variability analysis |
